# OpoSapiens Studio — OpoArcade & Street Opositor Fighter

Plataforma interactiva de gamificación para el estudio y preparación de oposiciones.

## 🎮 Modos de juego incluidos

1. **Street Opositor Fighter**: Combate por turnos estilo 16-bit retro (El Opositor vs. El Tribunal Calificador). Cada pregunta tipo test acertada asesta un golpe al Tribunal; cada fallo reduce la salud del opositor.
2. **El Rosco de la Opo**: Dinámica estilo Pasapalabra con 21 conceptos y definiciones jurídicas clave ordenadas alfabéticamente.
3. **Sopa de letras jurídica**: Tablero interactivo para encontrar términos legales y conceptos procedimentales (LPAC, LCSP, TREBEP).

## 🚀 Despliegue en GitHub Pages

Este repositorio está configurado para ejecutarse directamente como web estática (cero dependencias de servidor):

1. Ve a **Settings** > **Pages** en tu repositorio de GitHub.
2. En **Build and deployment** > **Source**, selecciona **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Pulsa **Save**. En 1-2 minutos tendrás tu web activa en:
   `https://rmartinez676-spec.github.io/type-opos/`
